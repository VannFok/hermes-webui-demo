# Hermes WebUI Demo v1.0.0

## English

Initial public demo release of Hermes WebUI.

Highlights:

- Futuristic local WebUI for a four-agent Hermes team.
- Supports four configurable local agents.
- Local live server at `http://127.0.0.1:4173`.
- Agent message bubbles, composer, recent history, Telegram sync hooks, WSL command bridge, and cron display flow.
- Optimized HUD, startup animation, center ring effects, background, and message sound.
- Private runtime files are excluded from the release source repository.

Getting started:

```powershell
npm install
npm run start
```

Open:

```text
http://127.0.0.1:4173
```

## 中文

Hermes WebUI 的第一个公开 demo 版本。

亮点：

- 给四个 Hermes agent 使用的未来感本地 WebUI。
- 支持四个可配置的本地 agent。
- 本地服务地址：`http://127.0.0.1:4173`。
- 支持 agent 气泡消息、输入框、最近历史、Telegram 同步接口、WSL 命令桥接和 cron 展示流程。
- 优化了顶部 HUD、启动出场动画、中心灯环、背景和消息音效。
- 真实运行配置、历史、事件日志和私密环境文件不会进入公开仓库。

快速开始：

```powershell
npm install
npm run start
```

打开：

```text
http://127.0.0.1:4173
```
